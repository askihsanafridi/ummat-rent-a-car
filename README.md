# ummat-rent-a-car

Modern professional rent-a-car website for Ummat Enterprises Rent-a-Car, built with Next.js App Router, TypeScript, and Tailwind CSS.

## Pages

- Home
- About
- Fleet
- Services
- Booking
- Contact

## Development

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production

```bash
npm run build
npm run start
```
